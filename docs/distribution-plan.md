# 강의 사이트 전국 수학과 배포 계획

작성: 2026-10-31
대상: 실해석 사이트를 1차로 하고, 같은 엔진의 미시, 거시, 금융 사이트에 같은 틀을 적용한다.
전제: 서버 확장은 필요 없다. 정적 파일과 CDN 서빙으로 트래픽은 이미 감당된다. 병목은 신뢰, 대응표, 배포 형태, 접근성이다.
일정 전제: 11월 14일 AWS 시험까지는 신규 작업을 벌이지 않는다. 착수는 11월 4주차부터다.

## 1차, 신뢰 장치

### 1-1. 정오표 페이지
- 상태: 로컬 완성 (2026-10-31), 배포 대기. 데이터는 src/errata.ts, 페이지는 한영 /errata/ 라우트와 프리렌더, 홈과 챕터 헤더 링크까지 연결했다. 첫 항목은 2026-10-29 차트 높이 수정이다. 테스트 1970개와 빌드 366페이지와 사이즈 체크 전부 그린.
- 산출물: 사이트 안 정오표 페이지, 씬별 수정 내역과 날짜, 신고 반영 여부를 적는다. 페이지 머리에 현재 판의 기준일도 함께 적는다.
- 방식: 정오표 데이터를 파일 하나로 관리하고, 씬을 고치는 푸시에 해당 항목 추가를 함께 넣는다.
- 완료 기준: 정오표 페이지가 빌드에 포함되고, 최근 수정 1건이 실제로 등재돼 있다.
- 규모: 소.

### 1-2. 오류 신고 창구
- 상태: 정오표 페이지 아래 신고 안내와 GitHub 이슈 링크까지는 완성 (2026-10-31). 이슈 템플릿 파일만 남았다.
- 산출물: real-analysis 레포 이슈 템플릿 (씬 주소, 잘못된 내용, 근거 칸), 사이트 푸터와 정오표 페이지에서 링크.
- 완료 기준: 이슈 템플릿이 레포에 들어가고 사이트에서 한 번에 닿는다.
- 규모: 소. 이슈 템플릿 파일은 .github 아래라 웹에서 직접 넣어야 한다.

### 1-3. 라이선스 표기
- 산출물: 콘텐츠 라이선스 결정과 표기. 후보는 CC BY 4.0이다. 코드 라이선스와 분리해 적는다.
- 완료 기준: 사이트 푸터와 레포 README에 라이선스가 표기된다.
- 규모: 소. 결정은 도연님이 한다.

## 2차, 교재 대응표와 학기 진도

### 2-1. 교재별 대응표, 아이콘 방식
- 산출물: 교재 챕터와 씬의 대응 페이지. 대상 교재는 김김계 해석개론, Tao Analysis I과 II, Rudin PMA, Bartle Introduction to Real Analysis다.
- 표시 방식 (도연님 결정): 교재마다 모양과 색 아이콘 하나로 관리한다.
  - 김김계: 동그라미, 초록
  - Tao: 네모, 빨강
  - PMA: 별, 노랑
  - Bartle: 역삼각형, 파랑
- 씬 목록과 대응 페이지에서 각 씬 옆에 대응하는 교재 아이콘만 작게 붙는다. 아이콘에 가까이 가면 (hover) 그 교재의 장과 쪽수가 뜬다. 모바일에서는 눌렀을 때 같은 정보가 뜬다.
- 방식: 대응 데이터를 교재별 파일로 관리한다. 데이터 단위는 씬 곱하기 교재로, 장, 절, 쪽수를 적는다. 아이콘은 인라인 SVG 도형 하나로 그리고 색은 CSS 변수로 둔다. 대응이 없는 씬은 아이콘이 없고, 교재에만 있는 주제는 대응 페이지에서 빈칸으로 명시한다.
- 완료 기준: 네 교재 전부 대응표가 있고, 씬 기준 커버리지가 수치로 적혀 있으며, 대표 씬에서 hover로 쪽수가 실제로 뜬다.
- 규모: 대. 교재 목차와 쪽수 대조 작업이 본체다. 교재별 목차 확보가 먼저다.

### 2-2. 15주 진도 학습 경로
- 산출물: 학기 진도표 경로 1개. 주마다 씬 묶음과 연습문제를 배치한다.
- 방식: 기존 학습 경로 데이터에 주 단위 경로를 추가한다.
- 완료 기준: 경로 페이지에서 15주 전체가 한눈에 보이고 각 주가 씬으로 연결된다.
- 규모: 소에서 중. 2-1 대응표가 있으면 빨라진다.

## 3차, 자체 완결 배포 형태

### 3-1. 외부 CDN 의존 제거
- 현황: 실해석 의미 검색이 esm.run에서 라이브러리를, HuggingFace에서 모델 113MB를 받는다. 거시 사이트는 KaTeX를 CDN에서 받는다.
- 산출물: 라이브러리는 번들에 넣거나 자체 경로로 서빙한다. 모델은 자체 경로 정적 파일로 서빙하되, 첫 검색 때만 받는 늦은 로딩은 유지한다.
- 완료 기준: 네트워크를 외부 도메인 차단 상태로 두고 전 기능이 동작함을 확인한다.
- 규모: 중. 번들 크기 예산 재검토가 함께 간다.

### 3-2. 오프라인 묶음
- 산출물: 사이트 전체 오프라인 zip.
- 방식: 빌드 산출물을 그대로 묶는다. 상대 경로 기준이라 풀어서 열면 동작해야 한다.
- 완료 기준: zip을 풀어 네트워크 없이 대표 씬이 열람된다.
- 규모: 중. 빌드 경로 기준 점검이 본체다.

## 4차, 접근성

### 4-1. 수식 MathML 병행 출력
- 산출물: KaTeX 렌더에 MathML이 함께 나가 스크린리더가 수식을 읽는다.
- 완료 기준: 대표 씬 3개에서 스크린리더 음성으로 수식이 읽힘을 확인한다.
- 규모: 중. 렌더 경로가 엔진 공통 파일이라 네 사이트 동시 적용 대상이다.

### 4-2. 키보드 조작과 대비
- 산출물: 슬라이더와 재생 바의 키보드 조작 점검 결과와 수정, 본문 대비 기준 확인.
- 완료 기준: 마우스 없이 대표 씬 3개를 끝까지 조작할 수 있다.
- 규모: 중.

## 하지 않을 것

- LMS 연동, LTI, SCORM 패키징. 씬 단위 고정 링크로 충분하다.
- 계정 시스템과 학습 진도 저장. 개인정보를 받지 않는 현재 구조가 기관 도입에 유리하다.
- 학교별 맞춤판과 멀티테넌트.
- 서버 이전과 멀티 리전. 현재 호스팅으로 충분하다.
